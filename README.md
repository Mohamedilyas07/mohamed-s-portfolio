# Mohamed Ilyas — Portfolio

Technical Support & Implementation Engineer. Built with React, Vite, Three.js and GSAP.

## Run
```bash
npm install
npm run dev
```
Contact form uses Resend: put `RESEND_API_KEY=...` in `.dev.vars`, and run `npm run secret:resend` before `npm run deploy`.

Edit content in `src/components` (Work.jsx, Skills.jsx, Timeline.jsx, About.jsx) and replace `public/Mohamed_Ilyas_Resume.pdf` to update the resume.
